# 🔮 PROMPTIQUE AI — Precision Prompt Engineering Studio

> **Transform raw, unstructured ideas into ultimate, highest-performing AI prompts.**

A premium, minimalist web application designed to engineer any rough concept into an authoritative, structured prompt based on the **5-Pillar XML Standard**.

---

## ⚡ Key Highlights & Architecture

### Output Anatomy (5-Pillar XML Framework)
Every prompt synthesized adheres to strict structural determinism:
1. **`<role_and_objective>`**: Uncompromising persona anchoring and zero-ambiguity core directive.
2. **`<context>`**: Domain grounding, situational stakes, target audience, and edge conditions.
3. **`<rules_and_constraints>`**: 3–5 negative boundaries eliminating fluff, hallucinations, and generic platitudes.
4. **`<formatting_requirements>`**: Strict delivery format (Markdown tables, JSON schema, or executable protocols).
5. **`<chain_of_thought>`**: Mandatory `<scratchpad>` reasoning protocol forcing the model to calculate logic before answering.

### Studio Features
- **Instant Heuristic Engine**: Fast, client-side NLP processor that works 100% offline with zero API keys required.
- **Custom Cloud API Support**: Optional BYO API Key for live synthesis via Google Gemini 1.5 or OpenAI / OpenRouter models.
- **Interactive XML Inspector**: Visual card deconstruction of each XML pillar with individual section copy actions.
- **Markdown Code Block Tab**: Formatted, line-numbered code block with one-click copy.
- **Virtual Execution Simulator**: Interactive sandbox demonstrating how target LLMs reason inside `<scratchpad>` and output final deliverables.
- **Prompt Library & Local Storage**: Auto-save, search, star, and reload previously engineered master prompts.
- **Export Capabilities**: Download as `.md` file or copy full insight + prompt with one click.

## 🚀 How to Run Locally

### 1. Start the Server
```bash
node server.js
```
*Or using npm:*
```bash
npm start
```

### 2. Open in Browser
Visit **[http://localhost:3000](http://localhost:3000)** in your browser (Google Chrome, Microsoft Edge, Firefox, or Safari).
